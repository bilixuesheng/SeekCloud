# 开源版只有一个管理员账户

开源版是给部署者自己用的：谁把 SeekCloud 装在自己的服务器上，谁就是唯一的使用者。所以主站只有一个账户，即**管理员**。没有注册，也没有多账户。2026-11-07 用户定的："完全不做账户了，就是管理员账户""没有账户，就是给用户自己用的"。

- **登录只用密码**。第一次打开网页时设置管理员密码（至少 8 位），设完直接登录。用户定了不做防抢先：不要设置码，也不限时，部署好以后应尽快打开网页设置。
- 密码只存 scrypt 哈希，每个密码一个随机盐。同一个 IP 一小时内输错 10 次就暂停。
- 忘记密码时，在服务器上运行 `pnpm admin:reset-password`：生成一个随机密码并打印出来，所有设备退出登录。能登录服务器的人本来就能改数据库，所以这条路不另设验证。
- **GitHub 不是登录方式**，只在设置里关联，用来访问仓库。再关联另一个 GitHub 账号时，直接换成新的。
- 去掉了收费版里只为多账户存在的东西：邮箱验证码登录和注册、Google 登录、第三方身份的绑定和冲突处理、邀请码、内测席位、Turnstile 人机验证、换邮箱、删除账户、用户协议和隐私政策，以及发信（导出完成只在设置里显示，不发邮件）。
- 数据库里保留 `users` 表和那一条管理员记录，会话、环境、导出照旧挂在它下面，相关的代码基本不用改。ADR 0001 里"用户端"和"管理端"的区分也随之没有了：主站整个都是管理员用的。

## Considered Options

- **保留收费版的多账户和注册，只是默认关掉**：没有采用。邮箱验证码要配发信服务，邀请码、席位、协议、删除账户都要维护和测试，自己部署自己用的人用不上。
- **不要账户，靠反向代理的 Basic Auth 或内网挡住**：没有采用。很多人会直接把主站放到公网上；登录状态、在所有设备上退出、访问记录也都需要一个账户。

## Consequences

- 以后真要多用户（比如一个团队共用一台服务器），代价不小：
  - 要重新做注册或邀请、每个人自己的登录方式和找回密码，以及发信或别的通知渠道；
  - 管理员和普通用户要分开：谁能改服务器设置、谁能看别人的会话；
  - 宿主机和模型网关要按用户分配并发、记用量，GitHub 关联要按用户分开；
  - 接口里"只看自己的会话、环境"的检查还在（都按 `user_id` 过滤），这部分可以接着用，但没有测试再覆盖它们。
- 首次设置之前，谁先打开网页谁就能设置密码。被人抢先时，在服务器上运行重置命令就能拿回来。
