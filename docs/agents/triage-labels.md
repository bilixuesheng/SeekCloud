# 分诊标签

各个技能按五种分诊角色说话。下表把角色对应到本仓库实际使用的标签名。

| mattpocock/skills 里的角色 | 本仓库的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等维护者评估 |
| `needs-info` | `needs-info` | 等提出人补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已经写清楚，可以直接交给 Agent 做 |
| `ready-for-human` | `ready-for-human` | 需要人来做 |
| `wontfix` | `wontfix` | 不做 |

技能提到某个角色时（比如"打上可交给 Agent 的标签"），就用这张表里对应的标签名。
