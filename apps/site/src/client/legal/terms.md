欢迎使用云上求索。注册或使用本服务，即表示你已阅读并同意本协议及《隐私政策》。

## 1. 服务说明

- 云上求索是**独立的第三方服务，并非 DeepSeek（深度求索）的官方产品**。
- 你授权 GitHub 仓库后，我们在云端隔离环境（沙箱）中运行 AI Agent。Agent 依据你的指示读写代码、运行命令、推送分支、创建 PR。
- 本服务目前处于内测阶段，功能可能调整，服务亦可能中断。

## 2. 账户

- 内测期间需凭邀请码注册。
- 请妥善保管你的邮箱及已绑定的 GitHub、Google 账号。通过你的账户进行的操作，均视为你本人的行为。
- 账户不得转让、出售或出租。
- 未满 14 周岁的未成年人请勿注册。

## 3. 使用规范

你不得利用本服务从事以下行为：

- 发布或生成违反法律法规的内容，或侵犯他人的知识产权、隐私等合法权益；
- 将沙箱用于挖矿、扫描、攻击、发送垃圾信息、搭建代理或托管网站；
- 使用脚本批量注册、刷取用量，或规避频率限制及人机验证；
- 转售、分租本服务，或将其封装为接口向他人提供；
- 试图突破沙箱，或获取他人数据及我们的密钥。

## 4. 代码与内容

- 你的代码、对话以及 Agent 为你生成的内容，其权利均归你所有。
- 为提供服务，你授权我们在必要范围内存储、处理和传输上述内容，包括发送至模型服务商以生成回复。详见《隐私政策》。
- 我们不会使用你的代码和对话训练模型，也不会对其进行分析。

## 5. AI 生成内容

- Agent 的回复和改动由 AI 生成，**可能存在错误**。请自行审查后再决定是否采用。
- Agent 的改动均提交至独立的分支和 PR，不会直接修改你的主分支。合并前请仔细检查。
- 合并及使用上述改动所产生的后果，由你自行承担。

## 6. GitHub 授权

- Agent 仅能操作你授权的仓库。
- Agent 无法删除分支、推送标签，也无法修改仓库设置。
- 你可随时在 GitHub 上撤销授权。撤销后，使用相关仓库的会话将停止。

## 7. 暂停与封禁

- 如你违反本协议，或系统检测到异常的自动化流量，我们可能暂停或封禁你的账户。
- 被自动暂停的账户均将经过人工审核，你可以提出申诉。
- 账户被暂停或封禁后，你仍可导出数据或删除账户。

## 8. 服务变更与终止

- 我们将尽力保障服务稳定，但内测期间不保证服务持续可用。
- 如需停止服务，我们将至少提前 7 天通知你，以便你导出数据。

## 9. 责任限制

在法律允许的范围内，对于 AI 生成内容的错误、你仓库中的改动以及服务中断所造成的间接损失，我们不承担责任。

## 10. 协议变更

本协议发生重大变更时，我们将通知你，必要时请你重新同意。

## 11. 争议解决

因本协议或本服务产生的争议，双方应首先友好协商；协商不成的，任何一方均可依法向有管辖权的法院提起诉讼。
