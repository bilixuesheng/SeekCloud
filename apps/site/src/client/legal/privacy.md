本政策说明云上求索收集哪些信息、如何使用、与谁共享、保存多久，以及你享有的权利。云上求索是独立的第三方服务，并非 DeepSeek（深度求索）的官方产品。

## 我们收集的信息及用途

| 信息 | 收集时机 | 用途 |
|---|---|---|
| 邮箱 | 注册、登录 | 登录，发送验证码和通知 |
| GitHub 账号（用户名、ID）及访问令牌 | 使用 GitHub 登录或绑定时 | 登录；在你授权的仓库中读写代码、推送分支、创建 PR |
| Google 账号（邮箱、ID） | 使用 Google 登录或绑定时 | 登录 |
| 对话记录、Agent 操作记录 | 使用会话时 | 展示会话内容，供你继续使用 |
| 你的代码 | Agent 运行时 | 仅存在于你的沙箱中，用于完成你指定的任务 |
| 环境配置（环境变量、网络密钥） | 你填写时 | 在沙箱中使用 |
| IP 地址 | 注册、登录、发起会话、发送消息时 | 防范滥用和自动化攻击，详见下文 |

## IP 地址的记录

- 你注册、登录、发起会话或发送消息时，我们会记录你的 IP 地址。
- 该信息仅用于识别机器人流量、批量注册等滥用行为，以保护你和其他用户的账户安全。
- **保存期限为 90 天**，到期自动删除。

## 人机验证（Cloudflare Turnstile）

- 注册和发送登录验证码时，我们使用 Cloudflare Turnstile 确认操作者为真人。
- 登录页会加载 Cloudflare 的脚本，Cloudflare 将处理你的 IP 地址和浏览器信息；多数情况下无需你进行任何操作。
- Cloudflare 对上述信息的处理方式，请参阅 [Cloudflare 隐私政策](https://www.cloudflare.com/privacypolicy/)。

## 共享信息的服务商

我们仅向提供服务所必需的服务商共享信息，且仅限必要范围：

- **DeepSeek（深度求索）**：生成 Agent 的回复。你的消息以及 Agent 读取的代码和命令输出将发送至 DeepSeek 的接口。
- **GitHub**：代码托管。Agent 依据你的授权读写你的仓库。
- **Google**：仅在你使用 Google 登录时使用。
- **Cloudflare**：人机验证，详见上文。
- **Resend**：发送邮件（验证码和通知），将获取你的邮箱地址和邮件内容。

我们不会出售你的信息，也不会使用你的代码和对话训练模型。本网站未接入任何第三方统计或广告服务。

## Cookie 与浏览器本地存储

- **登录 Cookie**：用于保持登录状态，30 天后失效。
- **第三方登录临时 Cookie**：在使用 GitHub 或 Google 登录时使用，10 分钟后失效。
- **浏览器本地存储**：保存你选择的外观（浅色或深色），仅存储在你的浏览器中。
- 我们不使用广告或统计类 Cookie。

## 保存期限

- 对话记录将一直保存，直至你删除相应会话或账户。
- 沙箱中的文件：会话休眠 7 天后，随沙箱一并删除。
- IP 地址保存 90 天。
- 数据导出文件：打包完成后 24 小时内可供下载，到期即删除。
- 系统每晚备份一次，备份中的数据在 30 天内滚动删除。

## 信息安全

- 全站采用 HTTPS 加密传输。
- GitHub 令牌、环境变量和网络密钥均加密存储。
- 每个会话在独立的沙箱中运行。Agent 无法获取你的 GitHub 令牌：其推送代码须经由我们的代理，且仅能操作你授权的仓库。

## 你的权利

- **查看与修改**：在设置中修改邮箱，绑定或解绑 GitHub、Google 账号。
- **退出登录**：在设置中一键退出所有设备。
- **撤回 GitHub 授权**：可随时在 GitHub 上撤销。
- **导出数据**：在"设置 → 隐私"中导出账户资料、全部对话（JSON 与 Markdown 格式）及环境配置（密钥已脱敏）。打包完成后将通过邮件通知，24 小时内可供下载；每 24 小时可导出一次。
- **删除账户**：在"设置 → 账户"中删除。经邮箱验证码确认后，账户立即停用：所有设备退出登录，已绑定的 GitHub、Google 账号解除绑定，正在运行的会话终止。其余数据将在 15 天内彻底删除，且不可恢复。GitHub 上的分支和 PR 不受影响。被封禁账户删除后，我们仍将保留一份不可还原的身份摘要，以防止再次注册。

本服务不面向未满 14 周岁的未成年人。

本政策发生重大变更时，我们将通知你，必要时请你重新同意。
